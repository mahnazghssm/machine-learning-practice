# Machine Learning Practice

This repository contains my practice work as I learn statistics, data processing, data visualization, and machine learning step by step. I use it to keep my code and exercises as I learn.

## Structure

### Statistics

Descriptive statistics, probability, and the basics of statistics and data types.

### Data_Processing

NumPy and Pandas fundamentals, along with exploratory data analysis.

### Data_Visualization

Practice with Matplotlib and Seaborn, including different types of plots and visualization exercises.

### Machine_Learning

Starts with probabilistic modeling, optimization, and parameter estimation, then moves into regression, classification, unsupervised learning, and ensemble methods, with an introduction to neural networks.

## Status

This repo is actively growing as I continue learning and practicing. Regression and the earlier statistics and data processing topics are done. I am currently working on classification, unsupervised learning, and ensemble methods.
