# Machine Learning Practice

I built this repository to practice different parts of machine learning while continuing to improve my Python skills. I use it to keep my code and exercises as I learn.

## Structure

**Data_Processing**
NumPy and Pandas, including arrays, dataframes, indexing, filtering, merging, grouping, and exploratory data analysis.

**Statistics**
Descriptive and inferential statistics, probability, and different types of data and variables.

**Data_Visualization**
Practice with Matplotlib and Seaborn for data visualization and plotting.

**Machine_Learning**
Probabilistic modeling, optimization, parameter estimation, regression, classification, unsupervised learning, ensemble methods, and an introduction to neural networks.

## Status

This is an ongoing practice repository. I add new work as I continue learning each topic.
