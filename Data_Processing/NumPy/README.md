# NumPy

Practice for the NumPy section of the data processing course on [Pytopia](https://www.pytopia.ai/courses/data-processing-for-ml/course-overview). NumPy is the library for working with arrays of numbers quickly, and almost every other data science library is built on it.

## What I plan to practice

- Introduction to NumPy
- Creating arrays: vectors, matrices, and higher-dimensional arrays
- Indexing and slicing, including boolean and fancy indexing
- Data types
- Broadcasting
- Vectorization: doing math on whole arrays without loops
- Mathematical operations
- Array manipulation, such as reshaping and combining arrays
- Sorting and searching

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- NumPy
