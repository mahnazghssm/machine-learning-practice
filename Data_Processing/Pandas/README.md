# Pandas

Practice for the Pandas section of the data processing course on [Pytopia](https://www.pytopia.ai/courses/data-processing-for-ml/course-overview). Pandas is the library for working with tables of data, and it is the tool I will use the most to prepare data for machine learning.

## What I plan to practice

- Introduction to Pandas
- Series and DataFrames
- Selecting data
- Applying functions to Series and DataFrames
- Handling missing values
- Handling duplicate data
- String manipulation
- Date and time
- Categorical data
- Merging, joining, and concatenating DataFrames
- Grouping and aggregating data
- Reshaping data and pivot tables
- Database fundamentals

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- Pandas
