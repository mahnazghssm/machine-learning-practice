# Data Processing

Practice for the data processing course on [Pytopia](https://www.pytopia.ai/courses/data-processing-for-ml/course-overview). A machine learning model can only learn from clean, well-organized data, so this is where I practice loading, cleaning, and preparing it.

## What I plan to practice

- [NumPy](NumPy): fast numerical computing with arrays
- [Pandas](Pandas): working with tables of data
- Exploratory data analysis: understanding a dataset and getting it ready for a model
  - Examining data types and structure
  - Handling missing data and duplicates
  - Normalization and standardization
  - Finding outliers
  - Encoding categorical variables
  - Feature engineering: creation, transformation, extraction, and selection

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- NumPy
- Pandas
