# Machine Learning

Practice for the machine learning course on [Pytopia](https://www.pytopia.ai/courses/machine-learning-i/course-overview). I want to start with the math behind machine learning, so the models I use later don't feel like black boxes.

## What I plan to practice

**Probabilistic modeling**

- Random variables and probability theory
- Moments
- Common discrete and continuous probability distributions
- Frequentist and Bayesian inference

**Optimization**

- Introduction to optimization
- Gradient descent and its variants

**Parameter estimation**

- Maximum likelihood estimation
- Bayesian estimation

**Supervised learning: regression**

- Simple, multiple, and polynomial linear regression
- Regularization: L1 and L2
- Evaluation metrics for regression
- A project on the tips dataset

**Scikit-learn**

- Data representation
- Estimator API and Pipeline API
- Hyperparameter tuning
- Model persistence

**Supervised learning: classification**

- Generalized linear models and logistic regression
- Decision trees
- Naive Bayes
- K-nearest neighbours
- Support vector machines
- Classification evaluation metrics

**Unsupervised learning**

- Clustering: K-means and density-based clustering
- Dimensionality reduction: feature extraction and feature selection
- Association rule mining

**Ensemble learning**

- Bagging and random forest
- Boosting
- Stacking and voting classifiers

**Neural networks and deep learning**

- The perceptron and basic network architecture
- Core concepts and training
- Practical implementation in Python
- Introduction to deep learning

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- scikit-learn

## Running the Notebook

Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

From the project root, open Jupyter Notebook:

```bash
jupyter notebook
```

Then open `Machine_Learning/practice.ipynb`.
