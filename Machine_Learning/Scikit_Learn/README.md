# Scikit-learn

Practice for the scikit-learn section of the machine learning course on [Pytopia](https://www.pytopia.ai/courses/machine-learning-i/course-overview). Scikit-learn is the main Python library for building machine learning models, and this is where I practice using it.

## What I plan to practice

- Introduction to scikit-learn
- Data representation: how features and targets are organized
- Estimator API: the common way to fit and use any model
- Pipeline API: chaining preprocessing and modeling steps together
- Hyperparameter tuning
- Model persistence: saving and loading trained models

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- NumPy
- Pandas
- scikit-learn

## Running the Notebook

From the project root, open Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Machine_Learning/Scikit_Learn/practice.ipynb
```
