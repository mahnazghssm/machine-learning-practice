# Statistics

Practice for the statistics course on [Pytopia](https://www.pytopia.ai/courses/statistics/course-overview). Before building models, I want to understand what the numbers in a dataset actually mean.

## What I plan to practice

**Introduction**

- What statistics is and what it is used for
- Types of data
- Types of variables

**Describing data**

- Averages: mean, median, and mode
- Variability: how spread out the data is
- The normal distribution
- Correlation: how two variables move together
- Simple regression: predicting one value from another
- Regression accuracy: how good the predictions are
- Regression toward the mean
