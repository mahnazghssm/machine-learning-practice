# Data Visualization

Practice for the data visualization course on [Pytopia](https://www.pytopia.ai/courses/data-visualization/course-overview). A good chart can show in seconds what a table of numbers hides, so I want to practice turning data into plots that are easy to read.

## What I plan to practice

- [Matplotlib](Matplotlib): the basic plotting library in Python
- [Seaborn](Seaborn): statistical plots built on top of Matplotlib

## Real-world datasets

I also want to visualize three real datasets:

- Titanic
- Housing prices
- Breast cancer

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- Matplotlib
- Seaborn

## Running the Notebook

From the project root, open Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Data_Visualization/practice.ipynb
```
