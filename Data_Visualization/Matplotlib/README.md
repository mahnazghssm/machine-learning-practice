# Matplotlib

Practice for the Matplotlib section of the data visualization course on [Pytopia](https://www.pytopia.ai/courses/data-visualization/course-overview). Matplotlib is the basic plotting library in Python, and other libraries such as Seaborn are built on top of it.

## What I plan to practice

- Introduction to Matplotlib
- Figures and axes: how a plot is built
- Basic plot types

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- Matplotlib

## Running the Notebook

From the project root, open Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Data_Visualization/Matplotlib/practice.ipynb
```
