# Seaborn

Practice for the Seaborn section of the data visualization course on [Pytopia](https://www.pytopia.ai/courses/data-visualization/course-overview). Seaborn makes statistical plots simpler and nicer to look at, and works directly with Pandas DataFrames.

## What I plan to practice

- Introduction to Seaborn and its plot types
- Relational plots
- Distribution plots
- Categorical plots
- Regression plots
- Matrix plots
- Multi-plot grids
- Controlling figure aesthetics

## Notebook

- `practice.ipynb`

## Requirements

- Python 3.9 or later
- Jupyter Notebook
- Seaborn

## Running the Notebook

From the project root, open Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Data_Visualization/Seaborn/practice.ipynb
```
